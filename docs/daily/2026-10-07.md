# Part 2 — Give every hour its own place

Today we built a timeline with exactly one row for every hour. When several source rows described the same hour, we kept the agreed vehicle count once. Missing hours now have an empty count, while real zero counts remain zero. This prevents duplicated observations or missing time from misleading future models.

We also froze three periods: training before 2017, validation during 2017, and final testing in 2018. Training teaches a model; validation helps choose an approach; final testing evaluates the chosen approach on later data. No forecasting model was trained today.

The timeline has 52,551 hourly slots: 40,575 observed and 11,976 missing. Training has 25,329 observed hours, validation 8,713, and testing 6,533. Training coverage is only about 68%, so we must be honest about incomplete history. The source's timezone ambiguity is still documented.

We delivered the preparation program, reproducible CSV outputs, a fingerprint manifest, a cleaning policy, and an executed quality notebook. All 15 unit tests passed. Notebook checks reconciled raw timestamps, missing values, time spacing, partition boundaries and file hashes. Weather fields remain in the raw source until their use is justified; the new table is deliberately target-only.
