# Part 5 - Test whether learned models beat simple forecasts

Completed 15 October 2026. Today we trained two kinds of model: Ridge, which combines inputs in a regularized linear formula, and a tree model that can learn more flexible patterns. We chose settings using the second half of 2016, then checked them on 2017. Every training boundary respects the two-hour reporting delay, and the final holdout stays sealed.

On the same 8,713 observed validation hours, the tree model averaged 190.2 vehicles/hour of absolute error. The weekday/hour baseline averaged 278.7; Ridge averaged 381.1. A more complicated model did not automatically win: the linear model was worse than the simple baseline. The tree model is our provisional choice, with temporal stability checks still needed.

Both learned models produced forecasts even with missing historical readings. We reported the 565 incomplete-input targets separately; the tree's error there was 211.3 vehicles/hour. The weekly baseline used a documented fallback on 46 targets. We did not hide difficult hours by silently dropping them.
